# Exercise 5 - Bootstrap 5

Project React dựng lại đầy đủ 5 giao diện trong file bài tập. Trang **Students Detail** (mẫu 5) là trang mặc định.

## Chạy project

```bash
npm install
npm start
```

## Mở từng mẫu

- Mẫu 1: `http://localhost:3000/?exercise=1`
- Mẫu 2: `http://localhost:3000/?exercise=2`
- Mẫu 3: `http://localhost:3000/?exercise=3`
- Mẫu 4: `http://localhost:3000/?exercise=4`
- Mẫu 5: `http://localhost:3000/`
